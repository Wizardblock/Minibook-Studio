MiniBook Studio {version} for Mac

1. Drag "MiniBook Studio" into your Applications folder (or run it from here).
2. The first time, right-click (or Control-click) the app and choose Open, then Open again.
   The app is not signed with an Apple developer certificate yet, so a plain double-click is refused.
   If you still see "cannot be opened": System Settings > Privacy & Security > "Open Anyway".
   Or in Terminal:  xattr -dr com.apple.quarantine "/Applications/MiniBook Studio.app"
3. To try it, drop samples/sample_library.csv onto the Books tab.

This build is for Apple Silicon Macs.
Project page: https://github.com/Wizardblock/Minibook-Studio
