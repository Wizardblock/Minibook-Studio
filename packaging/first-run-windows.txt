MiniBook Studio {version} for Windows (portable)

This is the no-install version: unzip it anywhere and run MiniBookStudio.exe.
(Prefer a normal install with a Start menu entry? Use the MiniBook-Studio-Setup file instead.)

Windows may say "Windows protected your PC" because the app is not signed yet.
Click "More info", then "Run anyway".

To try it, drop samples\sample_library.csv onto the Books tab.

Project page: https://github.com/Wizardblock/Minibook-Studio
