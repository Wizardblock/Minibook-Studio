## Which file do I download?

| You use | Download | Then |
|---|---|---|
| **Windows** | `MiniBook-Studio-Setup-{version}.exe` | Double-click, press Next. Choose "More info" then "Run anyway" if Windows warns you (the app is not signed yet). |
| **Windows, no install** | `MiniBook-Studio-windows-portable-{version}.zip` | Unzip and run `MiniBookStudio.exe`. |
| **Mac** (Apple Silicon) | `MiniBook-Studio-{version}-macos-arm64.dmg` | Drag the app onto Applications. First time: right-click the app, Open. |
| **Linux Mint, Ubuntu, Debian** | `minibook-studio_{version}_amd64.deb` | Double-click it and press Install. It finds what it needs. |
| **Other Linux** | `MiniBook-Studio-{version}-x86_64.AppImage` | Right-click, Properties, Permissions, "Allow executing", then double-click. |

Try it with `samples/sample_library.csv` (in the install folder, or in the project's `samples` folder).
Checksums are in `SHA256SUMS.txt`.
